# Счёт снукера

Согласовано 30 октября 2026. Два игрока ведут счёт на одном телефоне. Русский интерфейс, iPhone и Android равноправны. PWA работает без сети после первой загрузки. Данные локальны, без аккаунта и синхронизации.

## Игра

Имена игроков, 6/10/15 красных, цель по победам (по умолчанию 15 красных и до 2 побед), выбор начинающего. Начинающие чередуются. Один активный матч. Каждый шар, смена игрока и отмена — одно нажатие. Счёт фрейма и матча, серия, разница, остаток очков без будущих штрафов/свободных шаров. Фолы 4–7, удаление красных, выбор следующего игрока. В меню: несколько красных, свободный шар, восстановление позиции после фола без отмены штрафа, коррекция и сдача. Завершение фрейма подтверждается, равенство на последнем чёрном ведёт к переигровке чёрного. Приложение помогает, решения о законности принимают игроки. 6/10 красных — уменьшенный стол с тем же подсчётом.

## История и данные

История: дата, игроки, фреймы, лучшие серии, журнал. Просмотр и удаление с подтверждением. Автосохранение каждого действия. JSON-экспорт и атомарное объединение импорта: идентичные пропускаются, различающиеся одинаковые ID или второй активный матч блокируют импорт. Ошибки хранения видимы, ввод сохраняется в памяти, есть повтор. Конфликт вкладок не перезаписывает данные.
