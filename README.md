# Счёт снукера

[Открыть приложение](https://vtkndrew.github.io/snooker-score/) · [Каталог](https://vtkndrew.github.io/)

Счёт у стола на одном телефоне: два игрока, 6/10/15 красных, серии, фреймы и история. Русский интерфейс, работа офлайн после первой загрузки, без аккаунтов и сервера.

## Игра

Начните матч, введите имена, число красных и цель по победам. Тап по шару записывает забитый шар. «Смена игрока» завершает подход. «Отменить» возвращает предыдущий шаг текущего матча. «Фол» начисляет очки сопернику и позволяет выбрать продолжающего. Если шар забит с фолом, записывайте фол, а не результативный шар.

В «Ещё»: несколько красных за удар, свободный шар, восстановление позиции после фола (штраф остаётся), коррекция и завершение/сдача фрейма. Для восстановления позиции отмечайте фол отдельным действием. Спорные решения принимают игроки. 6/10 красных — сокращённый стол, без отдельного турнирного регламента. Подсказка остатка не включает будущие штрафы и свободные шары. После последнего чёрного подтвердите результат или выберите начинающего переигровки при равенстве.

Коррекция сохраняет ранее достигнутые лучшие серии. Для исправления ошибочного удара используйте отмену. Завершённые матчи доступны только для просмотра и удаления; перед подтверждением финального результата проверьте счёт.

## Данные и установка

Каждое действие записывается в IndexedDB. Надпись «Сохранено на устройстве» означает успешную транзакцию; при сбое ввод остаётся в памяти, доступны повтор и скачивание копии. Не закрывайте страницу с несохранёнными изменениями. Конфликт вкладок не перезаписывает свежую версию: сохраните копию и загрузите актуальное сохранение.

В меню «Приложение» доступны JSON-экспорт и импорт. Импорт объединяет отсутствующие матчи, пропускает идентичные, отказывает целиком при конфликте одинакового ID или втором незавершённом матче. Формат v1 проверяется повторным проигрыванием событий; неизвестные версии не импортируются. Предыдущих опубликованных версий схемы пока нет, база открывается с версией 1; будущие изменения потребуют явной миграции. Повреждённая база никогда автоматически не очищается.

Данные остаются в этом браузере, не синхронизируются и могут исчезнуть при очистке браузера или удалении приложения. Скачивайте копии. Safari и установленная iOS PWA могут иметь разные хранилища — перенос через JSON.

- iPhone: Safari → «Поделиться» → «На экран Домой».
- Android: Chrome → меню → «Установить приложение»; либо кнопка установки в приложении, когда браузер её предоставляет.
- Дождитесь «Готово к работе без интернета» в меню приложения перед использованием без сети.
- Обновление запускается с согласия после успешного сохранения и не удаляет историю.

## Разработка

Node.js 24 LTS (либо совместимый Node 22 ≥22.18). Зависимости закреплены в lockfile, реестр — npmjs.org.

```sh
npm ci
npm run dev
npm run format:check
npm run lint
npm run lint:architecture
npm run typecheck
npm test
npm run test:e2e
npm run test:pwa
npm run build
```

Локальные браузерные проверки используют установленный Chrome и Playwright WebKit (`npx playwright install webkit`); CI устанавливает Chromium/WebKit автоматически. `npm run icons` пересоздаёт PNG из локального SVG с использованием Chrome. После изменения кода запускайте `npm run lint:fix` и `npm run format`, затем проверки.

Dev работает на `/` без service worker. Production/preview — `/snooker-score/`. GitHub Actions выполняет проверки и публикует ветку main в GitHub Pages. Имена базы, кэшей и scope уникальны для приложения; чужие данные и кэши не затрагиваются.

## Ручная проверка на телефонах

Автотесты Chromium/WebKit не проверяют интерфейс установки ОС. На реальных iPhone и Android: установить приложение, создать тестовый матч, дождаться сохранения и готовности офлайн, включить авиарежим, записать серию, принудительно закрыть и открыть приложение, проверить счёт. Затем отключить авиарежим, применить обновление и проверить историю. Сделать экспорт/импорт между браузером и установленной PWA. Проверить расположение кнопок и экран с клавиатурой.

Продуктовые решения и словарь находятся в `docs/`.

## Зависимости разработки

На момент выпуска `npm audit --omit=dev` не обнаруживает уязвимостей. Полный аудит сообщает четыре low-предупреждения в цепочке сборки Workbox → node-resolve → deepmerge. Доступное автоматическое исправление откатывает PWA-плагин до несовместимой версии, поэтому оно не применено; в приложение эта цепочка не включается. Уязвимые high/moderate-зависимости инструментов обновлены совместимыми версиями.
